# MG4
## Devlog
FloatAnimation script makes the fish food GameObjects float up and down, having Start() set up the animation, while the Update() method runs every frame to move the fish food. The _up variable determines whether the food moves up or down, and the _timer variable keeps track of when to change direction. This makes the fish food continuously float up and down.
